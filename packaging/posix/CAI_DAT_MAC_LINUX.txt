H-logsen — Cài và mở trên macOS và Linux

Giải nén ZIP dành cho hệ điều hành của bạn vào thư mục có quyền ghi. Mỗi máy
tạo môi trường Python riêng. Lần cài đầu cần Internet. Trên macOS 14 trở lên,
dùng Python 3.10–3.13 64-bit từ python.org, ưu tiên Python 3.12. Trên Linux,
dùng Ubuntu 24.04 hoặc 26.04 x64 có giao diện đồ họa. Linux dùng Python hệ
thống (3.12 trên Ubuntu 24.04, 3.14 trên Ubuntu 26.04) vì chỉ bản này có thư
viện GTK/WebKitGTK cho cửa sổ desktop.

Mở Terminal tại thư mục vừa giải nén và chạy:

    sh Install-H-logsen.sh
    sh Open-H-logsen.sh

Trên macOS, nếu cần chọn Python khác:

    H_LOGSEN_PYTHON=python3.12 sh Install-H-logsen.sh

Trên macOS, gói ZIP còn có Install-H-logsen.command và Open-H-logsen.command
để mở từ Finder khi macOS cho phép. Lệnh Terminal ở trên cũng mở cùng cửa sổ
desktop. Cửa sổ macOS dùng WKWebView của hệ điều hành.

Trên Ubuntu 24.04 và 26.04, cài thư viện desktop trước khi chạy trình cài:

    sudo apt install python3-venv python3-gi python3-gi-cairo gir1.2-gtk-3.0 gir1.2-webkit2-4.1

Trên Linux, trình cài thêm H-logsen vào menu ứng dụng của tài khoản hiện tại
(~/.local/share/applications/h-logsen.desktop). Tìm "H-logsen" trong menu
ứng dụng để mở. Đặt H_LOGSEN_NO_LAUNCHER=1 khi chạy trình cài nếu không muốn
tạo lối tắt. Trình cài không ghi đè file h-logsen.desktop do chương trình khác
tạo. Nếu di chuyển thư mục đã giải nén, chạy lại trình cài để cập nhật lối tắt.

Mở app bằng tài khoản thường trong phiên đồ họa (Wayland hoặc X11). Không chạy
app bằng sudo.
Linux dùng WebKitGTK với Python hệ thống. Dùng các lệnh sau nếu
cần mở bằng trình duyệt hoặc lấy URL cục bộ trong môi trường headless:

    sh Open-H-logsen.sh --browser
    sh Open-H-logsen.sh --no-browser

Workspace, trình soạn thảo, terminal và phân tích tệp cục bộ dùng được mà
không cần cấu hình MySQL. Dữ liệu riêng của app mặc định nằm trong ~/.h-logsen.
MySQL cho luồng BGL đã nhập được cài và cấu hình riêng trên từng máy.
