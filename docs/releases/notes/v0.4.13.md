H-logsen 0.4.13 is the first release with native Linux packages, a redesigned interface in 15 languages,
and a hardened, fully reviewed codebase. Each package below was installed from scratch and opened in its
native window on Windows, macOS (Apple silicon and Intel) and Ubuntu by the release pipeline.

## Downloads

| System | Package | Requirements |
| --- | --- | --- |
| Windows 10 or 11, x64 | `H-logsen-0.4.13-Windows.zip` | Python 3.10 – 3.13 (64-bit), Microsoft Edge WebView2 Runtime |
| macOS 14 or later | `H-logsen-0.4.13-macOS.zip` | Python 3.10 – 3.13 from python.org |
| Ubuntu 24.04 or 26.04, x64 | `H-logsen-0.4.13-Linux.zip` | System Python, GTK 3 and WebKitGTK |
| Any (developers) | `H-logsen-0.4.13-source.zip` | Python 3.10 or later |

Extract the ZIP, run the installer once (`Install-H-logsen.cmd` on Windows, `sh Install-H-logsen.sh` on macOS
and Linux), then open H-logsen with `Open-H-logsen`. Compare the download with `H-logsen-0.4.13-SHA256.txt`.

## Highlights

- **Linux desktop.** Native window with WebKitGTK on Ubuntu 24.04 and 26.04, an application-menu launcher,
  glass palettes when the compositor supports them, and a browser fallback when no display is available.
- **Redesigned interface.** Icon navigation, a shared control system, a reorganized explorer and a compact
  toolbar; the H icon is used on every platform.
- **15 languages.** Every label is translated, with plural forms chosen per language and whole sentences
  instead of joined fragments.
- **Investigation platform.** One interface serves the synthetic demo and persisted MySQL datasets with
  identical responses; facet order is now stable when counts tie.

## Fixes

- A database-backed investigation request failed with an internal error when building detector facet labels.
- Database evidence reported an invalid raw page size as an offset error.
- BGL rows with empty content are kept; carriage-return-only uploads are rejected with a clear error; the
  parser rejects epochs inconsistent with the printed date (parser `bgl-1.1.0`; existing datasets keep `bgl-1.0.0`).
- Workers back off when the database is unavailable instead of stopping, and recover jobs left running by a
  stopped worker. Alert e-mail is claimed, sent and recorded in separate steps so a crash cannot resend it.
- Window evaluation reports trusted Loghub labels and user-supplied labels separately.
- Number and date formatting follow the interface language instead of always using Vietnamese.

## Security

- Content Security Policy with per-response nonces on every page.
- Owner-only storage for credentials, uploads, backups and model files, verified after writing.
- A stricter project-root sandbox: home, system, temporary and hidden roots, credential files, Windows 8.3
  aliases and reserved device names are refused.
- The interface language can only be changed from the application itself.

## Engineering

- ruff (lint and format) and mypy enforced in CI and pre-commit; typed contracts shared across layers.
- The largest functions were split into named steps, verified by equivalence harnesses over tens of
  thousands of generated inputs and a real MySQL pipeline.
- Migration `0005` adds indexes for worker polling, outbox dispatch and run-scoped paging, and CHECK
  constraints for outbox state and alert outcomes.
- Verified: 240+ tests without a database, 125 MySQL 8.4 integration tests, 26 browser end-to-end tests,
  Python 3.10, 3.13 and 3.14.

## Known limitations

- External SMTP delivery, deployment behind TLS and screen-reader certification are not verified.
- The private July model bundle is not distributed; that inference profile reports itself as unavailable.
